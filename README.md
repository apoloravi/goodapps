# GoodApps

Aplicativos e artefatos de distribuicao do projeto GoodX1988.

## Versoes

- [`good1988-v3.1.apk`](./releases/good1988-v3.1.apk): build assinada com otimização de recursos, marca GoodX 1988, correção do primeiro toque e tela sempre ativa.
- [`good1988-v3.2.apk`](./releases/good1988-v3.2.apk): corrige o encerramento ao abrir a lista de canais.
- [`good1988-v3.3.apk`](./releases/good1988-v3.3.apk): mantém a tela ativa durante filmes e canais.
- [`good1988-v3.4.apk`](./releases/good1988-v3.4.apk): consulta o Gestor App remoto e usa o painel publicado com fallback local.
- [`good1988-v3.5.apk`](./releases/good1988-v3.5.apk): vincula o APK ao cadastro `app_id=3` exibido no Gestor App.
- [`good1988-v3.6.apk`](./releases/good1988-v3.6.apk): envia heartbeat autenticado para listar o dispositivo no Gestor App.
- [`good1988-v3.7.apk`](./releases/good1988-v3.7.apk): aplica logo, banner e tema preto/dourado.

Detalhes tecnicos e o contrato do Gestor App estão em [`docs/goodx1988-v3.1.md`](./docs/goodx1988-v3.1.md).
